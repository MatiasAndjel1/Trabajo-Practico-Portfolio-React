# Portfolio Personal - Matías Andjel
 
Trabajo Práctico N°1 - Programación 4.
 
Portfolio personal de una sola página desarrollado con React y Vite, dividido en componentes reutilizables.
 
## Tecnologías utilizadas
 
- React
- Vite
- JavaScript
- JSX
- CSS
## Instalación
 
1. Cloná el repositorio o descargá el código.
2. Instalá las dependencias:
```bash
npm install
```
 
## Ejecución en desarrollo
 
```bash
npm run dev
```
 
Esto abre el proyecto en `http://localhost:5173` (o el puerto que indique la consola).
